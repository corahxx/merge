# 数据清洗功能说明

> 本文档描述「数据清洗」模块的能力、数据导入方式、清洗规则与结果导出。**后续修改功能时请同步更新本文档。**

---

## 1. 功能概述

对充电站/充电桩等表格数据进行标准化清洗，包括空值处理、主键(uid)生成、日期统一、单位换算、缺失与异常校验等，规则详见《数据清洗规则》文档。支持三种数据导入方式，清洗完成后可下载或保存到指定文件夹。

---

## 2. 入口与页面结构

- **侧栏**：在功能选择中选择「🧹 数据清洗」进入本模块。
- **双入口**：
  - **合并后进入**：从公共桩/充电站等多表合并结果页点击「数据清洗」进入，此时待清洗数据为合并结果表（`df_for_clean` 已存在），直接进入清洗配置与执行。
  - **从本模块上传/加载**：在数据清洗页选择「数据导入方式」并加载数据后，进入同一套清洗配置与结果界面。
- **主区流程**：选择/加载数据 → 选择数据类型（充电站 / 充电桩）→ 一键清洗或自定义规则 → 查看报告与导出（或保存到链接所在文件夹）。

---

## 3. 数据导入方式

在数据清洗页未加载数据时，需先选择以下三种方式之一并完成加载。

### 3.1 直接导入（小量级数据）

- **适用**：小量级数据，通过网页上传单文件。
- **操作**：选择「直接导入」→ 使用文件上传控件选择本机 Excel 或 CSV 文件。
- **支持格式**：.xlsx、.xls、.csv（CSV 优先 UTF-8-sig，失败则 gbk）。
- **行为**：选择文件后自动解析并进入清洗配置，不写入服务器磁盘；结果仅通过「下载 Excel/CSV」导出。
- **Session**：不设置 `clean_save_dir` / `clean_source_basename`。

### 3.2 连接数据库

- **适用**：数据在 MySQL 或 PostgreSQL 中，与数据透视表使用相同的连接方式。
- **操作**：选择「连接数据库」→ 选择数据库类型（MySQL / PostgreSQL）→ 填写主机、端口、用户名、密码、数据库名、表名；PostgreSQL 需填写 Schema。
- **预填**：选择 PostgreSQL 时，表单预填与数据透视表一致（主机 localhost、端口 5432、用户名 postgres、密码 Admin2026、数据库名 evdata、Schema rowdata、表名 evdata_2512_row），所有项均可修改；MySQL 与 PostgreSQL 使用独立 session 键，互不覆盖。
- **可选**：「最大行数」限制单次拉取行数（默认 100 万），避免大表一次性加载导致超时或内存不足。
- **行为**：点击「加载数据」后从数据库执行 `SELECT * FROM 表 LIMIT 最大行数`，将结果加载为 DataFrame 并进入清洗配置；清洗结果仅通过「下载 Excel/CSV」导出，不写回数据库。
- **依赖**：与数据透视表一致（pymysql、psycopg2-binary）。
- **Session**：不设置 `clean_save_dir` / `clean_source_basename`。

### 3.3 输入文件链接

- **适用**：数据在本机（或服务器可访问）的 Excel/CSV 文件路径，希望清洗结果**直接保存**到各路径所在文件夹，且**无需先加载数据**。支持**多文件**：一次粘贴多个路径，依次按相同规则清洗。
- **操作**：选择「输入文件链接」→ 在**多行文本框**中填写文件路径，**每行一个**，不同链接之间**换行**分隔（空行忽略；支持去首尾空格与引号）→ 点击「**开始配置清洗**」（不执行「加载数据」）。
- **支持格式**：.csv、.xlsx、.xls（执行清洗时 Excel 仅读第一个 Sheet）。
- **校验**：点击「开始配置清洗」后，对每一行路径校验：文件存在且扩展名为 .csv/.xlsx/.xls。**全部通过**才进入配置；若有无效行，在界面列出错误（如「第 2 行：文件不存在」「第 4 行：仅支持 .csv/.xlsx/.xls」），不写入 session。
- **行为**：进入配置后与其它导入方式相同（选择数据类型、一键清洗或自定义清洗），**不预览待清洗数据**。点击「一键清洗」或「执行自定义清洗」时，对 **`clean_source_paths`** 中的每个路径**依次**：读取文件 → 按当前选定的类型与规则清洗 → 将结果保存到**该文件所在文件夹**（生成「该文件 basename_已清洗.csv」与「该文件 basename_已清洗.xlsx」）。某条路径失败时**跳过并记录**，继续下一条；全部结束后展示「共 N 个文件，成功 M 个，失败 K 个」及失败列表；**清洗报告**与**清洗后数据预览**取**最后一个成功**文件的 DataFrame 与报告。
- **路径**：为服务器本机路径（与 CSV 格式转换「输入本地路径」一致）。
- **Session**：设置 `clean_path_input`（多行原文）、`clean_source_paths`（通过校验的绝对路径列表）、`clean_source_from_path=True`；不设置 `df_for_clean`，执行时按需读取。兼容旧版：若仅有 `clean_source_path`（单路径），视为单元素列表进入配置。

---

## 4. 清洗配置与执行

- **数据类型**：充电站数据 / 充电桩数据，决定适用的规则集合（见《数据清洗规则》）。
- **一键清洗**：按当前数据类型执行全部适用规则。
- **自定义清洗**：勾选要执行的规则后点击「执行自定义清洗」。
- **报告**：展示日期清洗成功/失败数、W→kW 换算条数、充电站内部编号缺失、无法识别日期格式样例、设备开通时间异常等；详见界面与规则文档。

---

## 5. 结果导出与保存到链接文件夹

- **导出文件名**：可修改「导出文件名（不含扩展名）」后使用下载按钮。
- **下载 Excel / 下载 CSV**：当数据为直接导入或连接数据库加载时，将清洗后 DataFrame 导出为浏览器下载。
- **输入文件链接**：数据由「输入文件链接」并「开始配置清洗」进入时，不先加载数据。执行「一键清洗」或「执行自定义清洗」时，对配置的每个路径**依次**读取、清洗，并将该文件的结果**自动**保存到**该路径所在文件夹**（`{该路径所在目录}/{该文件 basename}_已清洗.csv` 与 `.xlsx`）。单文件时提示「结果已保存到：xxx」；多文件时提示「共 N 个文件，成功 M 个，失败 K 个」，并可选展开失败列表与成功保存路径列表。无「保存到链接所在文件夹」按钮（结果已直接写入）。预览与下载为**最后一份成功**清洗的结果。

## 6. 涉及文件与模块

| 文件 / 位置 | 说明 |
|-------------|------|
| `merge_app/app.py` | 数据清洗页入口；三种数据导入方式 UI（直接导入、连接数据库、输入文件链接）；输入文件链接为多行文本框、换行分隔多路径、`clean_source_paths` 与依次清洗；数据库连接表单与「加载数据」；清洗配置、一键/自定义清洗、多文件批量结果汇总；下载按钮与「保存到链接所在文件夹」按钮。 |
| `merge_app/handlers/data_clean_handler.py` | 清洗规则定义、按表类型规则列表、`clean_dataframe`、表类型检测等（无改动）。 |
| `merge_app/handlers/pivot_handler.py` | 新增 `load_table_from_db`：按数据库类型、连接参数与最大行数从表加载 DataFrame，供数据清洗使用。 |
| `merge_app/数据清洗规则.md` | 清洗规则详细说明（空值、uid、日期、单位、校验等）。 |

## 7. 修改功能时的文档同步建议

- 新增或删除数据导入方式：更新 **2. 入口与页面结构**、**3. 数据导入方式** 及 **6. 涉及文件与模块**。
- 调整数据库连接项或默认值：更新 **3.2 连接数据库**。
- 修改「保存到链接所在文件夹」的路径规则、多文件逻辑或文件名：更新 **3.3 输入文件链接**、**5. 结果导出与保存到链接文件夹**。多文件方案详见 `数据清洗-多文件链接导入方案.md`。
- 修改清洗规则或报告内容：更新 **4. 清洗配置与执行**，并同步《数据清洗规则》文档。
