# 数据透视表功能说明

> 本文档描述「数据透视表」模块的能力、入口、配置项与实现要点。**后续修改功能时请同步更新本文档。**

---

## 1. 功能概述

数据透视表用于在导入数据或连接数据库后，通过选择**行字段**、**列字段**、**值字段**及**聚合方式**，生成类似 Excel 数据透视表的二维汇总表，支持筛选与导出。

- **数据来源**：支持 (1) **导入文件**（Excel/CSV）、(2) **连接数据库**（MySQL / PostgreSQL）。
- **字段识别**：导入或连接后自动识别所有列，供用户选择行/列/值。
- **筛选**：可选「按取值选择」（从某列去重值中多选）或「输入条件」（文件用 Python 表达式，数据库用 SQL WHERE 子句）。
- **聚合**：值字段支持 求和、计数、平均值、最大值、最小值 等，可多选。
- **输出**：页面预览（行索引会转为普通列以便完整显示），支持导出 Excel / CSV。

---

## 2. 入口与页面结构

- **侧栏**：在功能选择中选择「📊 数据透视表」进入本模块。
- **主区**：
  1. 选择**数据来源**：导入文件 / 连接数据库。
  2. **导入文件**：上传单文件（.xlsx / .xls / .csv），解析为 DataFrame，展示列名与预览；大表建议不超过 100 万行，超限会截断并提示。
  3. **连接数据库**：选择数据库类型（MySQL / PostgreSQL），填写连接信息并点击「获取表字段」拉取列名（不拉全量数据）；PostgreSQL 需填写 Schema（默认 public）。
  4. **配置透视表**：在已有列上配置筛选、行字段、列字段、值字段及聚合方式，点击「生成透视表」一次性执行。
  5. **结果**：展示透视表（可左右滑动查看宽表），提供「下载 Excel」「下载 CSV」。

---

## 3. 数据来源

### 3.1 导入文件

- **支持格式**：.xlsx、.xls、.csv。
- **规则**：首行为表头；CSV 优先 UTF-8-sig，失败则尝试 gbk；Excel 仅读第一个 Sheet；行数上限 100 万，超限截断并提示。
- **存储**：解析后的 DataFrame 存入 `st.session_state.pivot_source_df`，供后续筛选与透视使用。

### 3.2 连接数据库

- **数据库类型**：MySQL、PostgreSQL (psql)，通过单选切换。
- **MySQL**：主机、端口（默认 3306）、用户名、密码、数据库名、表名。
- **PostgreSQL**：主机、端口（默认 5432）、用户名、密码、数据库名、Schema（默认 public）、表名。
- **默认值**：选择 PostgreSQL 时，表单可预填本地常用配置（主机 localhost、用户 postgres、密码、数据库名、Schema、表名等），所有项均可修改。
- **依赖**：MySQL 需 `pymysql`，PostgreSQL 需 `psycopg2-binary`（见 `requirements.txt`）。
- **流程**：填写连接信息 → 点击「获取表字段」→ 仅拉取表结构（列名），不拉数据；透视与筛选在点击「生成透视表」时在数据库侧执行（聚合下推到 SQL）。

---

## 4. 筛选（可选）

- **不筛选**：使用全部数据。
- **按取值选择**：选择「筛选字段」→ 点击「获取该字段可选值」→ 在多选框中勾选要保留的值；文件数据从 DataFrame 取去重值，数据库从表内 `SELECT DISTINCT` 取（有数量上限）。
- **输入条件**：
  - **文件**：使用 Python 表达式（如 `age > 18 and city == '北京'`），内部用 `df.query()` 执行。
  - **数据库**：使用 SQL WHERE 子句内容（不含 `WHERE` 关键字），如 `age > 18 AND city = '北京'`。

筛选在点击「生成透视表」时统一生效；设置阶段除「获取该字段可选值」外不跑重查询。

---

## 5. 透视配置

- **行字段**：多选，对应透视表的行维度，顺序表示层级。
- **列字段**：多选，对应列维度。
- **约束**：行、列至少填一项。
- **值字段与聚合**：选择一个值字段，勾选 求和、计数、平均值、最大值、最小值 中的若干项；可多选聚合，同一列会得到多列结果（如「销量_加总」「销量_计数」）。
- **生成**：点击「生成透视表」后，先应用筛选（若有），再在内存（文件）或数据库（连接 DB 时）执行聚合，结果展示并可导出。

---

## 6. 聚合方式与支持范围

- **文件数据**：支持 加总(sum)、计数(count)、计数非空、平均值(mean)、最小值(min)、最大值(max)、首次(first)、末次(last)；见 `pivot_handler.AGG_MAP`。
- **数据库**：支持 加总(SUM)、计数(COUNT)、平均值(AVG)、最小值(MIN)、最大值(MAX)；在 SQL 中用 GROUP BY + 聚合函数，大表在库内完成，不拉全量。

---

## 7. 结果展示与导出

- **预览**：结果表使用 `st.dataframe` 展示；若存在行索引（如多行维度），会先 `reset_index()` 转为普通列，避免最左列被隐藏；列多时可左右滑动查看。
- **导出**：
  - **下载 Excel**：带行索引时导出会包含索引列。
  - **下载 CSV**：UTF-8-sig，带行索引时同样包含。

---

## 8. 涉及文件与模块

| 文件 / 位置 | 说明 |
|-------------|------|
| `merge_app/app.py` | 侧栏入口、数据来源选择、数据库表单、筛选/行/列/值 UI、生成与结果展示、导出按钮；数据源与配置的 session_state 管理。 |
| `merge_app/handlers/pivot_handler.py` | 文件透视 `build_pivot_table`；筛选 `filter_dataframe`、`get_distinct_values`；数据库 `get_db_columns`、`get_db_distinct_values`、`build_pivot_from_db`（MySQL/PostgreSQL 分支）；聚合映射 `AGG_MAP`。 |
| `merge_app/requirements.txt` | 依赖：pandas、openpyxl、xlrd、pymysql、psycopg2-binary。 |

- 修改导出格式或预览逻辑：更新 **7. 结果展示与导出**。
